# Public questionnaire package

This folder contains a de-identified, English-language version of the physics-comprehension questionnaire collected from people who completed the ball-collision task.

## Files

- `questionnaire_data_public.csv`: de-identified respondent-level data.
- `questionnaire_data_public.xlsx`: workbook with `Data`, `Codebook`, and `Results` sheets.
- `questionnaire_codebook.csv`: variable definitions, source question numbers, and response coding.
- `analyze_questionnaire.py`: reproducible analysis script for the requested comparisons.
- `questionnaire_outputs/`: statistical tables, transition table, JSON summary, report, and figure generated by the script.

## De-identification and restructuring

- The source submission timestamp was removed.
- New respondent IDs (`P001`, `P002`, ...) were assigned for the public file.
- Completion time was retained as a numeric duration in seconds because it is not a direct identifier and is useful for auditability.
- The original question labels were reordered into public item IDs `q01` through `q12`.
- The source question number is retained only in the codebook so the public variables can be mapped back to the manuscript's original Q13 and Q14 labels.
- Original Chinese response labels were translated to English.
- The source multi-select field for original Q15 is represented as pipe-separated English categories in the `q09_original_q15_judgment_basis` column.

## Requested tests

At the user's request, both comparisons use paired-samples t-tests on respondent-level binary indicators:

1. Original Q14: the 2D billiards interpretation is compared with the 3D zero/microgravity interpretation, conditional on selecting one of those two focal responses.
2. Original Q13 versus original Q14: the 3D gravity-consistent choice and the 3D zero-gravity-consistent choice are compared within the same respondents.

The reported mean difference and t statistic use category 2 minus category 1. Because the responses are binary, these t-tests should be understood as the requested analysis of paired respondent-level indicators.

The statistical interpretation is intentionally limited to reported task understanding and condition-associated differences. It should not be presented as a unique causal test of an internal gravity-prior violation or updating process.

## Reproduction

From this folder:

```text
python analyze_questionnaire.py
```

The script uses `pandas`, `numpy`, `scipy`, and `matplotlib`.
